# Home Lab Linux Server

I restored a non-working old PC and turned it into a Linux home server.

## What I did

- Cleaned the hardware and repaired damaged wiring
- Installed Q4OS (Debian based) and set it up as a server
- Ran a small local AI model (Qwen 2.5 0.5B) using llama.cpp on 3 GB of RAM
- Tried Jellyfin as a media server
- Installed Nginx as a web server and proxy

## What I learned

- Hardware troubleshooting from the cable up to the operating system
- Linux server basics: services, users, permissions, and networking
- Running AI models locally on old hardware
